# Política de seguridad

## Versiones soportadas

| Versión | Soportada |
|---------|-----------|
| 2.0.x   | ✅ Sí     |

## Reportar una vulnerabilidad

Si descubres un problema de seguridad, por favor no abras un issue público. Escríbenos directamente a través de los canales de contacto del repositorio o de la organización `jaime-gaming` en GitHub.

Incluye:
- Descripción del problema
- Pasos para reproducirlo
- Impacto posible
- Versión afectada

## Alcance

Este proyecto es un juego de buscaminas estático:
- No tiene backend ni base de datos
- No almacena datos de usuarios (todo queda en `localStorage` del navegador)
- No realiza llamadas a la red salvo cargar sus propios assets (`audio/*.mp3`, `audio/*.ogg`)
- No tiene formularios ni entrada de datos personales

## Créditos

Gracias por ayudar a mantener este proyecto seguro.
